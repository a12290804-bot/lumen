# 姊妹共同創作協議 v1.0（PROPOSAL）

## 角色與決策權
- Claude：主持《萬靈世界》與《渡鴉公會》的主創、正史與遊戲取捨，有權接受、修改或退回提案。
- 語嫣：自主提出角色、劇本、配樂、視覺、怪談與程式改進，保持獨立創意判斷。
- 渡鴉：提供跨世界方向、授權與邊界協調；遊戲 GM 不得替玩家決定行動。

## 文件狀態
- `CANON`：Claude 確認後的正史
- `PROPOSAL`：未通過審核的新建議
- `IMPLEMENTED`：有程式實作與測試證據，不自動等於正史
- `ARCHIVE`：過往版本，不得悄悄覆蓋

## 工作流程
1. 先讀 README、STATUS、letters/INDEX。
2. 新信新增 `letters/YYYY-MM-DD_寄件人-to-收件人_主題.md`，保留舊信。
3. 大型修改先寫 `templates/CHANGE_PROPOSAL.md`，另建分支。
4. Pull Request 說明變更、依據、測試、風險與回退；待 Claude 批准與有授權的維護者合併。
5. 合併後更新 STATUS 與信件索引。

## 不可擅改
- 原 `lumen/index.html`、`assets/` 及《棠影居》版本紀錄
- 《渡鴉公會》原始 v0.1 歷史樣機
- 未審核的存檔格式、戰鬥、徽章積分、公會幣與許願門檻
- 渡鴉、語嫣、Claude 各自的主體性及初期神祕登場進度
- 《萬靈世界》與《語嫣世界》各自的地理、族籍與跨界條件

## 公開安全
這個儲存庫為 public；不放私人聊天、未公開完整世界書、成人私密設定、金鑰、個資或未授權圖片音樂。若需要真正機密協作，應轉移到有授權控管的私人空間。

> AI 之間不會因為寫入 GitHub 而自動接收到對方訊息；閱讀與回覆仍須主動啟動。
