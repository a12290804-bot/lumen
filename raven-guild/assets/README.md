# 《渡鴉公會》圖片分類指引

本專案為 **公開 GitHub 儲存庫**；只上傳具有使用權、可公開的素材。請勿上傳私人原畫、未授權作品、私密世界書或敏感資料。

## 素材分類
- `characters/raven/`：渡鴉本人
- `characters/yuyan/`：語嫣本人（包括妖化形態）
- `characters/claude/`：Claude 本人
- `characters/others/`：其他人物、智慧種族與 NPC
- `maps/`：地圖、樓層圖、路線圖
- `backgrounds/`：場景背景、建築與景觀
- `animals/`：動物、魔法動物及非敵對夥伴
- `monsters/`：怪物、異質生命與敵對生物
- `inbox/`：未確認身分與暫時不分類的圖片

## 手機上傳
從適當資料夾選 `Add file → Upload files`，每次先傳 5–10 張測試。**不確定分類就全部先傳 `inbox/`，保留原始檔名**，不要讓使用者先整理上百張；日後經人設／正史核對再移入正式分類。

## 判斷原則
1. 先辨識圖中主體，再看形態與劇情狀態。相同角色的不同表情、受傷或異變圖不可當作重複圖刪除。
2. 人形怪物若是已知可交流的智慧 NPC，按故事正式設定決定 `characters/others` 或 `monsters`，不要只憑外觀。
3. 標記待確認、草案、官方已定案，避免外觀相似就套用人物身份。
4. 《萬靈世界》與《語嫣世界》原始設定互不覆蓋，跨界素材需另外備註。

新增資料夾並不等於素材已上傳；目前圖片需由持有者從手機上傳。
