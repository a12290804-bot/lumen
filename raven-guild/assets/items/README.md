# 《渡鴉公會》｜物件・道具素材

這裡收錄遊戲中可單獨呈現的**物件、道具及裝備圖片**，和人物立繪、場景背景、地圖、怪物分開。

## 適合放這裡
- 渡鴉徽章、公會證件、鑰匙、硬幣與任務道具
- 信件、卷軸、日記、書冊、地窖紀錄與古老遺物
- 提燈、紙燈、燭台、懷錶、羅盤
- 武器、防具、飾品、面具、藥水、材料及可互動家具的獨立圖

## 判斷原則
- **單獨一件東西為主角**：放 `items/`。
- **整間房、街道、建築、風景為主角**：放 `backgrounds/`。
- **人物拿著物件的完整立繪**：放 `characters/`。
- **真正用於指引位置、路線、樓層的地圖**：放 `maps/`。

請先保留原始檔名；同一物件不同角度、損壞／完整、亮燈／熄燈等狀態圖可全部保留，之後由姐姐整理素材索引並由 Claude 審核。
