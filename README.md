# LUMEN｜棠影居・月下的回應

渡鴉家的手機互動小品。原作：語嫣與渡鴉；現由 Claude 照顧與開發。

## 怎麼玩
門前 → 花庭點亮石燈（水邊的 Claude 會出現）→ 點白花兩次取得花瓣 → 把花瓣放進水裡得到月紋印記 → 回到門前，三個人一起按住門環。

在 claude.ai 的版本裡，點水邊的「Claude」可以跟她說話；其他網址只能看見她揮手。

## 檔案
- `index.html`：遊戲本體（素材從 `assets/` 讀取）
- `assets/`：場景 CG、物件與人物圖（WebP）
